# 현장픽 설치 파일

현장픽은 현장별 법인카드·계좌 지출을 정리하고 영수증 사진을 붙여 엑셀 정산표를 만드는 Android 앱입니다. 이 저장소에는 설치 파일(APK)과 업데이트 정보만 있습니다.

## 설치

1. 오른쪽 **Releases**에서 가장 최신 버전의 `HyeonjangPick-<버전>-update.apk`를 휴대폰으로 내려받습니다.
2. 파일을 열면 Android가 "출처를 알 수 없는 앱" 설치 허용을 묻습니다. 내려받은 앱(브라우저나 파일 앱)에만 허용합니다.
3. 설치가 끝나면 앱의 안내에 따라 회사명과 카드 알림 가져오기를 설정합니다.

## 업데이트

1.3.0부터는 앱의 **설정 → 앱 업데이트**에서 새 버전을 확인하고 설치할 수 있습니다. 설치 전에 장부와 사진 백업 파일이 휴대폰의 다운로드 폴더에 먼저 저장됩니다. 업데이트는 기존 앱 위에 덮어 설치되며 기록은 그대로 남습니다.

앱을 지우고 다시 설치하면 휴대폰에 저장된 기록이 사라집니다. 앱을 지우기 전에는 **설정 → 장부·사진 백업과 복원**에서 백업 파일을 꼭 저장하세요.

## 개인정보

- 결제 기록과 사진은 휴대폰 안에만 저장됩니다. 앱이 외부 서버로 보내지 않습니다.
- 카드 알림을 읽으려면 Android 알림 접근 권한이 필요합니다. 등록한 카드·계좌 조건에 맞는 알림만 가져옵니다.
- 앱은 업데이트 확인을 위해 이 저장소의 `update.json`만 내려받습니다.

## 파일 확인

각 릴리스에는 `SHA256SUMS.txt`가 함께 있습니다. 내려받은 파일의 SHA-256 값이 같은지 확인할 수 있습니다.
